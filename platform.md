## 🛠️ Advanced: PlatformIO Support (Optional)
Prefer PlatformIO over Arduino IDE? We have got you covered!

### Setup:
1.Install PlatformIO IDE (VS Code extension)
2.Open the songs/dracula/ folder in VS Code
3.PlatformIO will auto-detect platformio.ini and install dependencies
4.Click Upload (✓ button) or run:

```bash
pio run --target upload
```

### Benefits:
✅ Auto library management
✅ Faster compile times
✅ Built-in serial monitor
✅ Easy multi-platform support
